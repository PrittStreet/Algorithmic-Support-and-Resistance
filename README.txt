SR-Analyzer — Support & Resistance Tool
========================================

PREMIERE INSTALLATION (une seule fois) :
  1. Double-cliquez sur  create_shortcut.bat
     -> Un raccourci "SR-Analyzer" apparait sur votre Bureau.

LANCER L'APPLICATION :
  - Double-cliquez sur "SR-Analyzer" (raccourci Bureau), OU
  - Double-cliquez directement sur SR-Analyzer.exe
  - Une fenetre noire (serveur) apparait  ->  NE PAS LA FERMER
  - Votre navigateur s'ouvre automatiquement apres 3 secondes
  - Si le navigateur ne s'ouvre pas : allez sur  http://127.0.0.1:8000

ARRETER L'APPLICATION :
  - Fermez la fenetre noire du serveur  (ou Ctrl+C dedans)

PARTAGER VOS DONNEES AVEC UN AMI :
  - Pour envoyer  : double-cliquez sur  export_data.bat
                    -> cree un fichier .db dans vos Documents
                    -> envoyez ce fichier par mail / cle USB
  - Pour recevoir : double-cliquez sur  import_data.bat
                    -> choisissez le fichier .db recu
                    -> relancez SR-Analyzer

VOS DONNEES :
  Toutes vos donnees sont dans  sr_data.db  (dans ce dossier).
  Sauvegardez ce fichier pour ne pas perdre vos sessions et filtres.

PROBLEMES COURANTS :
  - "Impossible de se connecter" : attendez 5 secondes, rechargez (F5)
  - Port 8000 deja utilise : fermez toute autre instance, ou redemarrez
  - L'application plante : copiez le texte de la fenetre noire et contactez votre admin
